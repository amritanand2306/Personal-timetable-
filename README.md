This React Native app provides:

## 🆘 Troubleshooting

### Habits Not Saving
- Close app and reopen
- Clear app cache (Settings → Apps → Anand's Schedule → Storage → Clear Cache)
- Reinstall if problem persists

### Shooting Log Entries Disappearing
- Same as above - clear cache
- Ensure you're saving before closing app

### Progress Bar Not Updating
- Refresh app by closing and reopening
- The percentage updates after each habit toggle

### App Crashes
- Uninstall and reinstall
- Ensure Android 5.0+
- Clear app data (Settings → Apps → Anand's Schedule → Storage → Clear Data)
